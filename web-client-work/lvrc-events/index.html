LVRC Events Payment & Registration

A live registration and payment service developed by PCGsoft for Liverpool Victoria Rowing Club. Race entries, relay teams and online payments come together in one booking journey.

Last reviewed 18 October 2026

Visit the live LVRC Events website →

Live — client project

Built for a rowing club’s event operations. The application source is private; this page introduces the public service.

The problem

Bring entries and payments together.

The club needed a simpler way to organise event registrations, individual races and relay entries alongside payments and organiser reporting. Those parts of the process need to agree, so an entry’s payment and registration status can be checked together.

The solution

One standalone event service.

PCGsoft developed an online registration and payment platform for the club. Participants can enter races, a payer can purchase multiple entries in one booking, and organisers have protected tools for administration, reconciliation and spreadsheet reporting.

Registration, payment and operations

Built around the event workflow.

Individual and relay entries.

Individual race registration and named four-person relay teams, with configured school-year eligibility checks for juniors and club-assigned adult classifications. Participation checks prevent duplicate active entries across bookings.

Verified online payments.

SumUp card payments are checked against the booking on the server. Reconciliation records payment results and transaction codes, rather than treating a browser return page as proof of payment.

Booking communications.

Automated confirmation emails provide booking details following verified payment. Scheduled financial summary emails support the club’s event administration.

Protected reporting.

Operator administration and the restricted reporting portal use separate access controls. Entry and payment exports support XLSX and CSV spreadsheet workflows, with dates of birth omitted from the entries workbook.

Technology

A focused web platform.

The application uses TypeScript on Cloudflare Workers, with Cloudflare D1 for data and Cloudflare Access for protected organiser functions. SumUp provides card payment processing, and Resend supports transactional email.

The implementation is private. Public visitors can explore the registration website; administrative tools and participant records are restricted.
