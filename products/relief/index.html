Relief

A public toilet finder designed around accessibility, privacy and dignity.

Last reviewed 31 August 2026

Early development

A public companion site is available at findrelief.co.uk.

What is Relief?

Relief is a React Native and Expo mobile prototype for finding safe, clean and suitable toilet facilities.

What problem does it solve?

Finding a suitable facility can be urgent, personal and difficult. Relief is intended to make that search more dignified and more informed.

How does it work?

The public repository describes map, list, facility detail, community and premium screens backed by planned or in-progress services. Several backend and platform flows still need end-to-end testing.

Key properties

  • Accessibility-first product direction.
  • React Native and Expo mobile app.
  • Typed service modules and shared design system.
  • Public documentation of current limitations.
Current status

The README calls Relief a partially connected prototype. Authentication, facility data, maps, moderation, notifications and premium features are not presented as complete.
