Whilom

History, where it happened: a web knowledge platform and mobile companion for UK heritage discovery.

Last reviewed 31 August 2026

Web MVP / active development

No public live URL is currently recorded.

What is Whilom?

Whilom connects places to people, stories, objects and journeys through a shared heritage graph.

What problem does it solve?

Heritage information is often spread across disconnected sources and visits. Whilom is intended to connect deep research with the real-world place a person is exploring.

How does it work?

The public repository describes a Next.js web client, an Expo mobile companion, shared domain packages, a Supabase database contract and a governed ingestion pipeline.

Who is it for?

People researching UK heritage, planning journeys and wanting the same history to follow them from desktop research to an actual site.

Current status

The repository describes a working web MVP and an active multi-phase build. The registry does not claim a production launch or a public demo URL.
