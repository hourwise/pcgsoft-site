Moirae Accord

A research and specification package for portable linked records, verifiable authority composition, evidence-backed external-effect settlement and falsification testing.

Last reviewed 21 September 2026

Accepted ACCORD-02 research/specification package

Accepted main records a bounded portable package and preregistered experiment design. It is not a production runtime.

Portable records.

ACCORD-02 defines linked records, verifier contracts, trust and evidence profiles, and machine-readable schemas or registries where the accepted specification requires them.

Authority composition.

The package describes authority attenuation and effective-authority composition. It is a specification boundary for reasoning about authority, not an authority provider or minting service.

Effect settlement.

Accord distinguishes intent, dispatch, occurrence, observation, attribution and settlement so external effects can be represented without collapsing a provider attempt into assumed success.

Falsification design.

The accepted package includes a preregistered falsification and experiment design. The experiment has not been executed and no empirical benefit is claimed.

Implementation boundary

Specification is not deployment.

Moirae Accord does not currently claim a production verifier implementation, execution runtime, authority minting, provider reconciliation ownership, completed empirical experiment or demonstrated empirical improvement.
