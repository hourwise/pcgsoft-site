Moirae Code

An early Fates host direction for governed coding, persistent memory and model choice.

Last reviewed 31 August 2026

Early construction / inspection-only

Public TypeScript repository; licence not identified in the reviewed metadata.

What is Moirae Code?

Moirae Code is a local-first, model-agnostic coding environment direction in The Fates ecosystem.

What problem does it solve?

Developers want to choose models without surrendering control of what a coding agent remembers, can access or is allowed to do.

How does it work today?

The public README describes an inspection-only host that exposes canonical host inspection, captures model tool calls as proposals and compares pinned peer inspection records.

What is not implemented in this slice?

The repository explicitly says it does not yet execute through Ananke, retrieve Mnemosyne context, start Horae sessions, execute a sandbox or perform content preflight.

Current status is part of the design.

Moirae Code is recorded here as an early host and provenance surface, not as a finished governed coding product.

FAQ

Can Moirae Code run governed actions now?

The current public README describes an inspection-only host and says governed execution is not yet implemented in this slice.

What does model-agnostic mean here?

It is the stated direction of supporting local or hosted coding models without making model choice itself the authority to access or change project state.
