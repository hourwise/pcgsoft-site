Moirae Console

Governed agent actions for the web, made visible to a human.

Last reviewed 31 August 2026

Release candidate / inspection-only

Apache-2.0 public repository.

What is Moirae Console?

Moirae Console is a human- and agent-facing demonstration of the boundary between WebMCP capability discovery and authorised action.

What problem does it solve?

A website can tell an agent what it can do. That description alone should not decide whether protected information may be disclosed or an action may be taken.

How does it work?

The release candidate exposes two fixed WebMCP tools: a read-only document inspection request and a fixed publication request. Governance determines whether the request is disclosed, sent for approval or denied.

What does the human see?

The Console presents three visible outcomes: ALLOW → DISCLOSED, REQUIRES_APPROVAL → APPROVE → PUBLISHED and restricted caller DENY → NOT EXECUTED.

FAQ

Does WebMCP grant an agent permission?

No. WebMCP can expose what a web surface can do; Moirae Console demonstrates why governance still needs to evaluate authority before disclosure or action.

Is the Console a production control plane?

The public repository describes a release candidate and inspection-only path. Treat it as a demonstration with explicit boundaries, not a universal security guarantee.
