Moirae Protocol

A Strands-powered operations agent that separates model proposals from deterministic action compilation, independent governance, human approval and evidence-aware effect reconciliation.

Last reviewed 21 September 2026

Submitted hackathon build — governed-agent reference implementation

Submitted to the Agents for Humans Hackathon. This is an early hackathon build, not production security software.

Proposal is not authority.

An agent or model may propose an administrative action, but the proposal is not itself permission to act. Deterministic Protocol code compiles the proposal into exact action material before independent governance considers it.

Governed execution.

Fates and Ananke provide independent admission and governance boundaries. Consequential actions can require durable human approval, while queue and execution state preserve action identity across recovery.

Effect truth stays explicit.

Horae separates a provider attempt from reconciled effect truth. When the evidence does not justify success, UNKNOWN remains visible rather than silently becoming a successful outcome.

Human-facing projection.

The reference build includes concepts such as Handled automatically, Needs you, Blocked and Activity so that governance state is visible to the person responsible for the work.

Claim boundary

A reference build, not a certification.

The public evidence differs in how strongly it describes successful live provider characterization. This page records the integrated architecture, accepted deterministic and governance milestones, and the bounded provider/reconciliation experiment without making an unqualified claim about completed live Bedrock calls, external effects or formal security certification.
